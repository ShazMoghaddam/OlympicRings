# Security

This project is a small set of Python scripts that read local data files and draw charts, and it holds no personal
data, passwords or keys.

## Reporting a problem

If you find a security issue, for example in the scripts or the GitHub Actions workflow, please don't open a public
issue. Use GitHub's private reporting instead: go to the **Security** tab of this repo and click
**Report a vulnerability**. You'll get a reply within a week.

For anything else, like a wrong number or a broken chart, an ordinary
[issue](https://github.com/ShazMoghaddam/OlympicRings/issues) is perfect.

## Supported versions

Only the latest version on the `main` branch is supported.
